## Featured Projects

### EcoAid (capstone project)
A full-stack, barangay-level recyclable waste management PWA. Residents submit pickup requests, barangay officials manage collections, and a superadmin oversees the system.

- Three user roles (resident, barangay official, superadmin) with httpOnly cookie authentication
- AI-assisted pickup requests: the Claude API recognizes items from a photo as a submission aid, and a human still verifies the result
- Validated with two real barangays, one formal and one informal
- Fixed a cross-domain cookie issue between a Vercel frontend and an Express backend by proxying API calls through Next.js rewrites
- **Stack:** Next.js, Node.js/Express, PostgreSQL (Neon), Prisma, Tailwind CSS, Cloudinary
- **Status:** development complete, preparing for capstone defense

### SplitPals
A bill-splitting PWA for groups, deployed live on Vercel and maintained based on real usage and feedback.

- Receipt scanner powered by the Claude API: photograph a receipt, the AI extracts items and prices, and you edit them before assigning to people
- Schema of User, Bill, Person, and Item, with totals derived on the fly instead of stored
- Multi-step registration and an animated onboarding carousel
- **Stack:** Next.js (App Router), Supabase, Tailwind CSS, Framer Motion
